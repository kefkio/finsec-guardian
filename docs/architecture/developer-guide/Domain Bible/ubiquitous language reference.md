Concept	Meaning
Finding	A security issue identified by an analyzer
SourceLocation	Physical location within a source file
CodeContext	Semantic location within the program
NormalizedCode	Canonical representation of source code
VulnerabilitySignature	Stable semantic identity of a vulnerability
Fingerprint	Deterministic hash used for tracking and deduplication
Scan	A single execution of one or more analyzers
Report	The aggregate result of a completed scan
Risk	The calculated business impact of findings
